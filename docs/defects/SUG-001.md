# [SUGGESTION] All pages: add SEO and link-preview metadata

## Summary

Pages lack common metadata for search engines and link previews. None of these is required by requirements v1.0, so this is an improvement suggestion, not a bug.

## Current behaviour

Checked on all 82 pages on 2026-10-07 (deploy `03ab24e`):

| Item | Now |
|---|---|
| `og:title`, `og:description`, `og:url` | Missing on every page |
| `og:image` | The logo on every page, including stream pages that have their own cover image |
| `twitter:card` | Missing |
| `<link rel="canonical">` | Missing. Every page is reachable as `/page` and `/page.html` |
| `hreflang` alternates between UA and EN | Missing |
| `/robots.txt`, `/sitemap.xml` | 404 |
| Title length | 23 pages over 60 characters (max 93) |
| Description length | 47 / 52 characters, same on every page (see BUG-001) |

## Suggested behaviour

- Per-page `og:title` and `og:description` (from the page title and frontmatter description), `og:url`
- Stream pages: their cover (`/streams/NNN.png`) as `og:image`; `twitter:card = summary_large_image`
- `canonical` pointing to one URL form
- `hreflang="uk"` / `hreflang="en"` alternates on each page pair
- `sitemap.xml` (VitePress has a built-in `sitemap.hostname` option) and a `robots.txt` that references it

## Why it matters

Stream links are shared in Telegram, LinkedIn and Discord. With per-page Open Graph data, the preview shows the stream title and cover instead of a generic logo. Search engines get the right page per language and one URL per page.
