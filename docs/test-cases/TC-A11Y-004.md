# TC-A11Y-004: Images have a text alternative

| Field | Value |
|---|---|
| Module | A11Y |
| Requirement | REQ-014 |
| Priority | Medium |
| Type | Accessibility |
| Automation | automated ([`tests/a11y.spec.ts`](../../tests/a11y.spec.ts)) |
| Author | |
| Created | 2026-10-07 |

## Preconditions

- The site is available (`/` returns 200).
- Desktop browser (C1), window ≥ 1280px wide, so the full header menu is visible.

## Test data

- Pages: `/`, `/speakers`, `/speakers/serhii-lytvyn`, `/streams/022`

## Steps

| # | Action | Expected result |
|---|---|---|
| 1 | Inspect every `<img>` on each page (DevTools Elements, or axe "image-alt") | Every image has an `alt` attribute. An image that is the only content of a link has a **non-empty** `alt` (it names the link) |
| 2 | Read the alt texts | Content images describe the content (speaker name, stream number); decorative images have `alt=""` |

## Postconditions

- None (read-only test).
