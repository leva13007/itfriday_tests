# [SUGGESTION] Wiki: `/wiki` and `/wiki/` end on a 404 page

## Summary

The wiki section has no index page. Typing the section URL leads to an error page.

## Current behaviour

- `https://itfriday.community/wiki` → 301 → `/wiki/` → 404
- `https://itfriday.community/en/wiki/` → 404
- The nav item "Вікі" links to `/wiki/mission`, so site navigation itself is fine

## Suggested behaviour

Add `wiki/index.md` (UA and EN) that either lists the 4 documents or redirects to `mission`.

## Why it matters

`/wiki` is the obvious URL to type or share for the section, and it currently ends on "PAGE NOT FOUND".
