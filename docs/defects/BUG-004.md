# [BUG] Posts and home: insufficient colour contrast in code blocks and the primary hero button

## Summary

Some text doesn't meet the WCAG AA contrast ratio of 4.5:1: the language label and comments in code blocks (both themes), syntax-highlighted tokens in the light theme, and the "YouTube Live →" button text in the light theme.

## Environment

| | |
|---|---|
| URL | https://itfriday.community/posts/2026-06-22-web-push-api, https://itfriday.community/ |
| Browser + version | Chrome 154, axe-core 4.10.2 |
| OS / device | macOS |
| Viewport | 1512×806 |
| Language | UA (same on EN) |
| Deploy | Tue, 06 Oct 2026 16:47:41 GMT (site commit `03ab24e`) |

## Steps to reproduce

1. Open the Web Push post in the dark theme and run an axe scan.
2. Switch to the light theme and scan again.
3. Open `/` in the light theme and scan.

## Expected result

Normal-size text has a contrast ratio of at least 4.5:1 (REQ-014; WCAG 1.4.3).

## Actual result

| Where | Theme | Example | Ratio | Nodes |
|---|---|---|---|---|
| Post: code block language label (`js`) | dark | #6a6a71 on #161618 | 3.36:1 | part of 18 |
| Post: code comments | dark | #6a737d on #161618 | 3.75:1 | part of 18 |
| Post: highlighted code tokens | light | various | < 4.5:1 | 63 |
| Home: "YouTube Live →" button | light | #ffffff on #5672cd | 4.48:1 | 1 |

## Severity / Priority

| Severity | Priority |
|---|---|
| Minor | Low |

The code colours come from the default syntax highlighting themes. The button is 0.02 below the threshold.
