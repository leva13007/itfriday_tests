# [BUG] All pages: every page shares the same meta description

## Summary

Every page has the same site-wide `<meta name="description">` instead of a description of its own content.

## Environment

| | |
|---|---|
| URL | All 82 pages, e.g. https://itfriday.community/streams/022 |
| Browser + version | n/a (HTTP response, checked with `curl`) |
| OS / device | macOS |
| Viewport | n/a |
| Language | UA and EN |
| Deploy | Tue, 06 Oct 2026 16:47:41 GMT (site commit `03ab24e`) |

## Steps to reproduce

1. `curl -s https://itfriday.community/streams/022 | grep 'name="description"'`
2. Repeat for `/about`, `/speakers/serhii-lytvyn` or any other UA page.
3. Repeat for any EN page.

## Expected result

Each page has a description of its own content (REQ-012), e.g. stream #022 describes the talk.

## Actual result

- All 41 UA pages: `Онлайн-ком'юніті для IT-спеціалістів по всьому світу`
- All 41 EN pages: `Online community for IT professionals worldwide`

## Severity / Priority

| Severity | Priority |
|---|---|
| Minor | Medium |

Search engines and link previews (Telegram, LinkedIn) show the same generic text for every stream, speaker and post.

## Evidence

Analysis of all 82 pages: 1 distinct description per language.
