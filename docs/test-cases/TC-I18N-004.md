## Preconditions

- The site is available (`/` returns 200).
- Desktop browser (C1), window ≥ 1280px wide, so the full header menu is visible.

## Test data

- Start page: `/wiki/values`
- Expected EN page: `/en/wiki/values`

## Steps

| # | Action | Expected result |
|---|---|---|
| 1 | Open `/wiki/values` | Ukrainian page loads |
| 2 | Open the language switcher in the header | A menu shows "Українська" (current) and "English" |
| 3 | Select "English" | `/en/wiki/values` opens: the same wiki page in English, not the EN home page |
| 4 | Open the language switcher again and select "Українська" | `/wiki/values` opens again |
