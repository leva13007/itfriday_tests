# TC-I18N-006: Interface texts on EN pages are in English

| Field | Value |
|---|---|
| Module | I18N |
| Requirement | REQ-004 |
| Priority | Medium |
| Type | UI |
| Automation | manual-only |
| Author | |
| Created | 2026-10-07 |

## Preconditions

- The site is available (`/` returns 200).
- Desktop browser (C1), window ≥ 1280px wide, so the full header menu is visible.

## Test data

- Pages: `/en/`, `/en/streams/022`, `/en/wiki/mission`, `/en/does-not-exist`

## Steps

| # | Action | Expected result |
|---|---|---|
| 1 | Open each page from the test data | Page loads |
| 2 | Read all interface texts: nav items, language switcher, theme toggle tooltip, footer, "Edit/Previous/Next" links, sidebar title, 404 texts | All interface texts are in English; no Ukrainian strings |
| 3 | Open the matching UA pages and repeat | All interface texts are in Ukrainian, including the "skip to content" link (press Tab once on load), the 404 page and the theme/menu labels |

## Postconditions

- None (read-only test).

## Notes

Interface texts come from the site config, not the page content, so they are easy to miss when only one locale is configured.
