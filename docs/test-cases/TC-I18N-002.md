## Preconditions

- The site is available (`/` returns 200).
- Desktop browser (C1), window ≥ 1280px wide, so the full header menu is visible.

## Test data

- Start page: `/streams/`
- Expected EN page: `/en/streams/`

## Steps

| # | Action | Expected result |
|---|---|---|
| 1 | Open `/streams/` | Ukrainian page loads |
| 2 | Open the language switcher in the header | A menu shows "Українська" (current) and "English" |
| 3 | Select "English" | `/en/streams/` opens: the same streams list in English, not the EN home page |
| 4 | Open the language switcher again and select "Українська" | `/streams/` opens again |
