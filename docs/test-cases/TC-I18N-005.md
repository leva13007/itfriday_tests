# TC-I18N-005: Every UA page has an EN counterpart and vice versa

| Field | Value |
|---|---|
| Module | I18N |
| Requirement | REQ-004 |
| Priority | Medium |
| Type | Functional |
| Automation | candidate |
| Author | |

## Preconditions

- The site is available (`/` returns 200).
- Terminal with `curl`; a local copy of the site repo, or the site map from `docs/requirements.md`.

## Test data

- Page list built as in links checklist L-A01

## Steps

| # | Action | Expected result |
|---|---|---|
| 1 | Build the list of UA pages (paths without `en/`) and EN pages (paths under `en/`) | Two lists. Record their counts (41 + 41 on 2026-10-07) |
| 2 | Strip the `en/` prefix from the EN list and compare it with the UA list | Lists are identical: no page exists in only one language |
| 3 | Request the EN counterpart of every UA page on the live site | Every counterpart returns 200 |

## Postconditions

- None (read-only test).

## Notes

Detects pages added in one language only, the most likely parity defect when a new stream page is published.
