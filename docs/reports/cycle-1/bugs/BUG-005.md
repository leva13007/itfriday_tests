# [BUG] Stream #007: `chrome://webrtc-internals` link can't be opened

## Summary

Stream page #007 (UA and EN) renders `chrome://webrtc-internals` as a clickable link. Browsers don't allow web pages to open `chrome://` URLs, so clicking it does nothing (or shows an error in the console).

## Steps to reproduce

1. Open https://itfriday.community/streams/007.
2. Find "chrome://webrtc-internals — інструмент відладки" in the content.

## Expected result

Either the text isn't a link (shown as code, e.g. `` `chrome://webrtc-internals` ``, with a note to paste it into the address bar), or the link leads somewhere that can be opened (REQ-008).

## Actual result

The link is rendered with `href="chrome://webrtc-internals"`. Clicking it doesn't navigate: Chrome blocks web pages from opening `chrome://` URLs.
