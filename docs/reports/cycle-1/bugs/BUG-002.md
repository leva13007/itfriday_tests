# [BUG] UA pages: interface texts are shown in English

## Summary

On Ukrainian pages, the built-in interface texts of the site theme (skip link, outline, pager, 404 page, menus) are in English.

## Environment

| | |
|---|---|
| URL | Any UA page, e.g. https://itfriday.community/wiki/values, https://itfriday.community/does-not-exist |
| Browser + version | Chrome 154 |
| OS / device | macOS; mobile viewport 390px for the mobile menu |
| Viewport | 1512×806 and 390×844 |
| Language | UA |
| Deploy | Tue, 06 Oct 2026 16:47:41 GMT (site commit `03ab24e`) |

## Steps to reproduce

1. Open https://itfriday.community/wiki/values.
2. Look at the right-hand outline title and the pager at the bottom of the page.
3. Press Tab once after the page loads (skip link).
4. Hover the theme toggle and the language switcher; check their tooltips and labels.
5. Narrow the window to mobile width and open the menu.
6. Open https://itfriday.community/does-not-exist.

## Expected result

All interface texts on UA pages are in Ukrainian (REQ-004).

## Actual result

| Element | Text shown |
|---|---|
| Skip link | Skip to content |
| Outline title (right sidebar) | On this page |
| Pager | Previous page / Next page |
| Mobile local nav button (wiki) | Menu |
| Mobile menu theme row | Appearance |
| Theme toggle tooltip | Switch to light theme |
| Language switcher label | Change language |
| Hamburger label | mobile navigation |
| 404 page | 404 · PAGE NOT FOUND · quote · Take me home |

| Minor | Medium |
