## Charter

Explore **the global UI (mobile menu, search, 404 page, footer) and the URLs around it** with **URL guessing, DOM inspection and cross-page comparison** to discover **behaviour the requirements don't describe**.

## Notes

- **URL variants.** Tried what a visitor might type: `/streams` → 301 → `/streams/` ✅. `/posts`, `/en` → 301 with a slash ✅. `/wiki` → 301 → `/wiki/` → **404**: the wiki has no index page, so the obvious section URL ends on an error page. `/about/`, `/speakers/`, `/schedule/` (trailing slash on a non-folder page) → 404. Upper case (`/Streams/`) → 404 (expected on GitHub Pages).
- **Search.** The header contains an empty `VPNavBarSearch` container but no search box. There is no site search. (Resolves the open question in requirements v1.0.)
- **Footer.** "ІТ П'ятниця · @zloyleva" / "IT Friday · @zloyleva" ✅. Same on every page.
- **Schedule page.** Says "Наступний стрім: Дата і тема будуть оголошені в Telegram" (*date and topic will be announced*). But stream #022 on 9 Oct 2026 is already announced on the site: in the streams list, on its own page, and with a scheduled YouTube live. **The site contradicts itself.**
- **Issues page.** Links to `github.com/leva13007/itfriday.community/issues` ✅ (resolves). It mentions four issue templates: matches the site repo's 4 templates ✅.
- **Cross-page data check** (scripted, all 22 streams × 2 languages): stream list vs. stream pages vs. speaker profiles. Dates, YouTube IDs and speakers match between UA and EN, and between the list and the stream pages ✅. **One mismatch:** stream #012 lists Олег Левченко as a participant (list and stream page), and Олег Таланов's profile includes #012, but **Олег Левченко's profile doesn't list #012** (UA and EN).
- **Mobile menu** (390 px): opens, locks page scroll ✅. Theme toggle inside the menu works ✅. Language submenu shows "English" ✅. **Escape doesn't close the menu** (the close button does).
- **Incident:** at ~11:36 UTC one request to `/streams/012` returned GitHub's "Unicorn!" error page. 3 retries a minute later → 200. githubstatus.com: Pages operational. A one-off hosting hiccup, not a site defect.

## Questions / observations

- Escape doesn't close the mobile menu. Acceptable under a11y check A11Y-B05 ("Escape **or** the close button"), but Escape is the common expectation. Confirm in the manual keyboard run.
- Trailing-slash variants of page URLs (`/speakers/`) return 404. Normal for GitHub Pages; only worth fixing if such links exist somewhere (none found on the site).
